S6｜コーチングって、何？

画面：コーチング = 「答えを引き出す」プロセス

話す内容：

ここで念のため、「コーチング」って言葉、聞いたことあってもピンと来ない方もいると思うので。 ひとことで言うと、コーチングは「答えを教える」じゃなくて、「あなたの中にある答えを引き出す」対話の手法です。 行動を止めている思考の癖、自分への評価の歪み。これを対話の中で一緒に見える化していくと、人は自然と動き出すんです。 いま、トップアスリートや経営者が必ず付けてる、注目の手法です。

S7｜思考→判断→行動→結果サイクル

画面：思考 → 判断 → 行動 → 結果

話す内容：

何かを身につけるとき、人は「思考」→「判断」→「行動」→「結果」のサイクルを回してます。 どう思うか。何をやると決めるか。実際に手を動かすか。結果が出るか。

S8｜唯一無二の差別化

画面：他社は "行動と結果" だけ。Vim は "思考と判断" から扱う

話す内容：

ここがすごく大事で──ほとんどの英会話スクールも、コーチングも、扱うのは "行動" と "結果" だけ。 でも本当は、その前にある "思考" と "判断" が止まっているから、行動が始まらない。 Vim は、ここから扱います。思考と判断の癖から解除する。これが Vim の差別化です。
